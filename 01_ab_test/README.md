# A/B-тест нового алгоритма рекомендаций

*Учебный проект. Данные предоставлены симулятором karpov.courses.*

## Задача
Оценить влияние нового алгоритма рекомендаций на CTR.
Группа 1 — контроль (старый алгоритм), группа 2 — новый алгоритм.

## Данные
Период: 28.08.2026 — 03.09.2026
Источник: simulator_20260920.feed_actions
Размер выборки: ~10 000 пользователей в каждой группе.

## Методы анализа
1. Обычный t-тест (p-value = 0.6854)
2. Тест Манна-Уитни (p-value = 0.0000)
3. Сглаженный CTR (p-value = 0.0517)
4. Бакетное преобразование (p-value = 0.0000)
5. Пуассоновский бутстреп (p-value = 1.0000, средняя разница = -0.009318)

## Вывод
Новый алгоритм не улучшил CTR. Средний CTR в группе 2 (0.2161)
ниже, чем в группе 1 (0.2168). Бутстреп подтверждает отрицательную разницу.

## Рекомендация
Не раскатывать новый алгоритм на всех пользователей.
Требуется доработка и повторное тестирование.
