# Линеаризация метрик в A/B-тестировании

*Учебный проект. Данные предоставлены симулятором karpov.courses.*

## Задача
Применить метод линеаризации (разработан в Яндексе) для анализа метрик-отношений.
Сравнить результаты с обычным t-тестом.

## Данные
Период: 28.08.2026 — 03.09.2026
Источник: simulator_20260920.feed_actions
Группы: 0 и 3 (контроль и тест), 1 и 2 (контроль и тест).

## Метод
Линеаризация: linearized_likes = likes - CTR_control * views.
Вместо «сырого» CTR анализируем линеаризованную метрику.

## Результаты

Для групп 0 и 3:
- Обычный CTR: p-value = 6.21e-44
- Линеаризованные лайки: p-value = 1.49e-58
- Линеаризация уменьшила p-value.

Для групп 1 и 2:
- Обычный CTR: p-value = 0.69
- Линеаризованные лайки: p-value = 2.98e-09
- Линеаризация уменьшила p-value.

## Вывод
Метод линеаризации резко увеличил чувствительность t-теста.
Там, где обычный CTR не видел разницы (p-value = 0.69),
линеаризованные лайки показали значимую разницу (p-value = 2.98e-09).

## Рекомендация
Использовать линеаризацию для анализа метрик-отношений (CTR, конверсия).
Метод быстрый, не требует тяжёлых вычислений и отлично подходит для A/B-тестов.
